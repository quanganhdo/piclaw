Scope and ranking meaning

This is a task-based purchasing/routing comparison, not a replay of production usage. Frontier = newest premium closed models (Fable 5.1, Astra). Precursor = earlier closed families (Sol/Terra, Fable 5). Open = models with published weights, accessed here through OpenRouter; this label does not imply low capability or unrestricted licences.

The order is my provisional trial recommendation for each workload, not a measured quality leaderboard. Public model-purpose descriptions, prices, our established Sol preference and the ability to validate outputs inform it. We have not run a matched benchmark of these models. Costs assume equal work and no retries; a better model can earn its premium by avoiding failures.

5 · How this fits current plans

  • API / OpenRouter: use the dollar estimates above as a top-up budget, not a flat-rate allowance. Start with capped spending and measure cost per successful task; no Azure or Cerebras price is silently substituted.
  • ChatGPT / Codex: Plus $20/month; Pro 5× $100; Pro 20× $200. A Plus trial is a lower-commitment way to test subscription capacity, but neither 2–3h/day nor API-equivalent dollars proves it will fit. Rolling and weekly usage limits depend on model and workload. Subscription access is through eligible products/integrations, not generic API credits.
  • Claude: Pro $20/month (or $200/year); Max from $100/month, with 5× and 20× usage tiers. Use eligible Claude/Claude Code access; do not count this as Anthropic API credit in Piclaw. Model entitlements and rolling limits need checking before selecting Fable as the default.
  • Copilot: Pro $10/month, Pro+ $39, Max $100. Currently displayed credit totals are $15 / $70 / $200, comprising base $10 / $39 / $100 plus variable flex allotments. The native Sol scenario is $49.52: above Pro and Pro+ base allowances, but within Pro+'s currently displayed total. Do not use the cheaper OpenRouter Sol quote to predict Copilot consumption. Premium-model access and other credit-consuming features can change the fit.

Practical recommendation: benchmark the mixed routing above against an all-Sol baseline. Pay for a premium subscription only if its eligible model access, successful-task rate and observed limits beat that API budget. The available evidence does not establish a guaranteed number of problems solved per plan.
