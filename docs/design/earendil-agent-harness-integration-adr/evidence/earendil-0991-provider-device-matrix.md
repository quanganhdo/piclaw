# Public Copilot and Kimi device methods on Earendil 0.99.1 (#1458)

GitHub Copilot and Kimi Coding public OAuth methods pass 22 synthetic device-flow cases under Bun 1.4.2 and real Node 26.7.0. This is package-method AUTH-03 evidence, not full SDK/CLI/UI, live-account or model-policy qualification.

## Provider-specific execution

The fixture imports public `builtinProviders()` and calls each provider's OAuth login. It pins exact pi-ai 0.99.1 plus the Copilot/Kimi OAuth and shared poller file fingerprints. File reads are provenance checks; no private executable imports or clock/timer substitutions are used.

Each provider covers pending→success, denial, malformed device response, malformed token response, cancellation during a blocked poll, real one-second expiry, server-directed slow-down, unsafe verification URI, and cancellation during initial/pending/slow-down sleeps. Public prompt/device events, endpoint, HTTP/form/header/client-ID fields and returned request auth are asserted.

Copilot first prompts for enterprise domain (blank synthetic answer). Its synthetic success path exchanges the GitHub token for a Copilot token and reads a catalog containing one enabled fixture model. Policy-write endpoints are unexpected and fail the fixture; no account policy change is qualified. Kimi emits its complete verification URL, including the synthetic code, and resolves request auth as a bearer header. Receipts exclude codes/tokens/URLs.

Pending poll gaps must be 0.9–3.5 seconds; server-directed two-second slow-down gaps must be 1.9–4.5 seconds. Real one-second expiry rejects before the first poll. Timer-wait cancellation must reject within 750 ms of the controller abort. The blocked-fetch case separately observes fetch-signal abort. Severe event-loop starvation can fail those upper bounds; it is not accepted as passing evidence.

All fetch targets are intercepted; unexpected endpoints fail. This is process-level fetch instrumentation without an OS network-sandbox claim. No credential store, inference or live endpoint is invoked.
