# Synthetic public Codex device flow on Earendil 0.99.1 (#1458)

Earendil 0.99.1's public Codex OAuth device route passes six synthetic cases under Bun 1.4.2 and real Node 26.7.0. This is package-only AUTH-03 evidence; it does not complete the provider device matrix or Piclaw's full CLI/UI acceptance.

The fixture imports public `builtinProviders()` and invokes `openai-codex.auth.oauth.login()`. Version checks and SHA-256 fingerprints pin the Codex OAuth module and its shared polling implementation to installed 0.99.1 bytes. Those files are read for provenance only; execution uses no private imports, runtime casts or clock/timer monkeypatches.

Every fetch is intercepted before it can reach a provider. The fixture asserts exact device-registration, polling and token-exchange endpoints, POST/content-type/signal, JSON/form fields, client ID and device redirect URI. Credentials and user codes are synthetic; receipts contain only aggregate outcomes and fingerprints. The fetch guard is process-level instrumentation without an OS network-sandbox claim.

| Case | Device requests | Polls | Token exchanges | Checked result |
|---|---:|---:|---:|---|
| Pending → success | 1 | 2 | 1 | OAuth credential, account ID and request auth |
| Access denied | 1 | 1 | 0 | Provider denial rejects before exchange |
| Malformed device response | 1 | 0 | 0 | Missing fields reject before polling |
| Malformed polling response | 1 | 1 | 0 | Missing code/verifier rejects before exchange |
| Cancel blocked poll | 1 | 1 | 0 | Supplied fetch signal aborts; cancellation is observed |
| Slow down → success | 1 | 2 | 1 | Inter-poll gap increases to at least 5.9 seconds |

The ordinary pending case checks a 0.9–5-second inter-poll gap around the real one-second minimum. The slow-down case checks the gap specifically between its two polls. No total-runtime inference substitutes for backoff behavior. Public device events retain their declared 900-second expiry and zero-second server interval; the package enforces the one-second polling minimum.

## Further qualification

The Codex route has a fixed 900-second expiry and no public clock seam; expiry is not executed here. Callback/browser modes have their separate earlier receipt. GitHub Copilot, Kimi and other provider-specific device routes need their own exact endpoint/event receipts. Piclaw card/UI device interaction, independent-process lifecycle, complete secrets/backups/traces, Delegate and approved live-account checks remain open. No deployment, restart or account operation follows these tests.
