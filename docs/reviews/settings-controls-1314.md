## Review corrections

The bounded @ux source review found two concrete issues, both corrected:

1. Unconditional secure-context `crypto.randomUUID()` for Classic DOM IDs would
   break supported HTTP/LAN panes. IDs now use module-local counters and stable
   refs; all core browser cases remove `crypto.randomUUID` before mounting.
2. Root-only Escape handling left a dropdown open when focus tabbed out. A
   bubbling `focusout` handler now closes without stealing outside focus. Tests
   exercise selection, Escape and Tab-out explicitly.

The independent model delegate timed out and is **not** counted as approval.
@ux cleared its source-level hold after both fixes; this is source review, not
independent execution of browser tests.
