# Core auth audit

Code authority: `runtime/web/src/login.ts`, `runtime/web/src/components/oobe-panel.ts`, `runtime/web/src/invitation.ts`, `runtime/web/src/ui/oobe-state.ts`, plus `runtime/web/src/login-policy.ts` for login body/policy invariants referenced by `login.ts`.

Not included as a canonical scenario: `provider-ready` rendering exists in `runtime/web/src/components/oobe-panel.ts::OobePanel`, but `runtime/web/src/ui/oobe-state.ts::resolveOobePanelState` currently returns only `hidden` or `provider-missing`.
